## 新增
- 点击宠物或气泡跳转 Herdr 时，herdr 派发的子 agent（`parent` 非空）改用 `terminal.peek` 在其父会话的 tab 上打开浮层窗口，可以直接看到子 agent 的画面。
- 气泡聚焦顺序新增同级子 agent 优先：同一优先级内子 agent 排在其父 agent 前，气泡显示与点击目标保持一致；父 agent 处于 blocked/error 等更高优先级时仍然优先。

## 修复
- 修复点击子 agent 时只停在父会话、看不到子 agent 输出的问题；`terminal.peek` 不可用时回退到父会话所在的 tab。
