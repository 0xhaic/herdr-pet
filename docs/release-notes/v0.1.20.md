## 新增

- 新增 Windows x64 版本：透明置顶宠物、拖拽与逐像素点击穿透、状态动画汇总、
  Direct2D 聊天气泡（Agent/状态图标、spinner、分页、展开收起、深浅主题）、
  点击跳转 Herdr、Toast 提醒与提示音、Win32 设置面板、任务栏托盘菜单。
- Windows 以单个 `herdr-pet-<version>-windows-x64.exe` 分发，无需安装器；
  配置写入 `%APPDATA%\herdr-pet\config.json`。
- Windows「关于」使用原生任务对话框，显示版本并提供「打开仓库」按钮。
- Windows CI 在 `v*` tag 上构建 exe，与 macOS dmg 发布到同一个 GitHub Release。

## 修复

- Windows：修复调整宠物大小或窗口 DPI 变化后气泡停止刷新并反复报
  `D2DERR_WRONG_RENDER_TARGET (0x88990015)` 的问题。

## 说明

- Windows exe 未签名，首次运行可能触发 SmartScreen：点击「更多信息」→「仍要运行」。
- Windows 首版无真实背景模糊（气泡为半透明填充），设置面板为经典 Win32 浅色外观。
- Windows 需要本机安装 herdr-core（`hc` 在 PATH 中）；Herdr 可选，用于前台判断、
  点击跳转与 Agent 图标。多显示器混合 DPI 尚未验证。
- macOS 本次无功能变化，继续提供 arm64 DMG；Windows 支持 Windows 10 1809+ /
  Windows 11 x64。

macOS arm64 DMG，未签名/未公证。首次启动请右键 → 打开，或执行：
`xattr -dr com.apple.quarantine /Applications/herdr-pet.app`
